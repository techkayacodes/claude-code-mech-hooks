# claude-code-mech-hooks 🔔⌨️

Drop-in **Claude Code** (`~/.claude/settings.json`) hooks generator that adds mechanical keyboard switch acoustic cues (`thock`, `clack`, `clicky`, `chime`) when Claude finishes a task (`Stop`) or requests user input (`Notification`).

Built by [Kemal Codes (@techkayacodes)](https://github.com/techkayacodes) as part of the [Keyboard Cheat Codes](https://github.com/techkayacodes/keyboard-cheat-codes) ecosystem.

## 🚀 Quick Usage

Generate a ready-to-paste `~/.claude/settings.json` hook block right in your terminal:

```bash
npx claude-code-mech-hooks --profile=thock
```
